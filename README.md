# grandmaclicker
A chrome extension clicker, using it's popup as a simple clicker, with *nothing* to look forward to.

## installation guide :)

### 1 Clone the repository.

Clone the repository using this command: `git clone https://github.com/gabe1031bit-school/grandmaclicker/` in your native terminal.

### 2 Navigate to the folder.

Use the command `cd grandmaclicker` in your native terminal.

### 3 Open the file in your File Explorer/Finder/etc.

Use the command `open .` for MacOS, `explorer .` for Windows, and `xdg-open .` for some versions of Linux. _Note the file path, you will need it._

### 4 Open your browser's native extensions menu.

To open your browser's native extensions menu, use `[your browser name]://extensions`. _(e.g. chrome://extensions, edge://extensions, opera://extensions, et cetera)._

### 5 Enable developer mode.

Click on the toggle to **enable** developer mode. If it is already enabled, no need to disable and enable it again.

### 6 Load unpacked extension.

Click on the new button named, `Load Unpacked`. Remember the file path you noted? Now find the folder using the path. That's it! Enjoy Grandma Clicker!
